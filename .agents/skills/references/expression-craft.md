# 表达技法：抖音口播

> 本文件是项目口语表达的详细权威。口播以平等、直接地说明为主，必要时提醒，承接读者正在处理的事情，讲清判断依据和必要条件。用户确认的本文件规则优先于旧学习手册和改写示范中的表达指标。表达调整不能改变事实命题、限定条件、因果强度或责任关系。

> **载体声明（2026-09-22）**：本文件按抖音口播载体编写。豆包客户端默认采用书面+口播两用模式，完整稿按 `docs/豆包书面图文模式.md` 执行（书面结构起稿、书面审稿、顾问式收尾）；本文件的口播标准在用户明确要求"短视频口播/抖音口播/口播稿"时适用。两用稿不套用本文件"每 5–8 秒一个有效信息点""结尾默认给一个明确动作"等口播专属条款，保留长句与信息密度；事实命题、限定条件、因果强度与责任关系不变。执行权威以 `generation-trigger-registry.md` 为准。

## 一、适用范围与事实底线

生成或改写完整中文口播稿时，从初稿开始执行以下规则；Humanizer 和质量门使用同一标准。标题候选只执行相关表达要求；诊断、资料出处和内部记录不套口播字数、语气词或 CTA。分镜不改写已确认文案。

样本用于学习语气、断句和讲述方法，不是事实来源。改写前锁定主体、动作、时间、数值、适用条件和结论强度；改后逐项核对。“可能跟着改”不能写成“工期预算全泡汤”，“必要时淋浴”不能写成全部都要淋浴，也不能新增“基本不会返工”。样本里的比例、亲测经历、对比效果和新闻范围，只有已核实才可使用。

## 二、平等、直接地说明

- 脱离标题，观众也能理解文案的对象和场景。第一句已经清楚时直接推进；第一句设置悬念时，最迟第二句补足必要语境。“你／你的”按交流需要自然使用，不强制出现在开头，也不限制固定次数。
- 语气以平等、直接地说明为主，必要时提醒。承接读者正在处理的事情，直接讲事实、判断和做法；确有必要提示时，说明该细节与本题的关系；不预设读者犯错，不反复警告、纠正或指挥读者。这是语气目标，不规定段落顺序，也不要求每段都写提醒。
- 口播默认避用“先别急着、不代表、可别、不能、当然”，以及“怎么……就……”这类带质问意味的表达。遇到这类表达，按整句和相邻段落重新说明事实、条件或做法，不只替换近义词。原始证据明确规定禁止或不适用时，准确表达该边界；温和语气不得把必要条件改成可选建议，或把有限结论扩大为绝对结论。
- 句子长短按意思和口播节奏安排。一句话塞入多个判断、主干不清或难以自然换气时，拆分或重写；能顺着说清的句子保留，不为缩短句长切断条件和逻辑。
- 口语感来自顺畅的句子和贴合语境的表达，不主动补口头禅，不设置口语词配额。“说白了、其实、啊、呢、嘛、吧”等按语境自然使用；“可以确认一下、顺便看看”也只是表达选择，不设为新的固定句式。
- 主语缺失、指代不明或责任不清时补足主语；上下文已经清楚时不机械重复。动词按原意和语境选择，不要求一律改成具体动作指令，语气保持平和。原意相符时，“进行核对”可改成“确认一下”，“需求成立以后”可改成“确认需求之后”；不机械替换，不改变动作、条件或承诺。
- 转折、因果、条件和补充关系优先由内容表达；朗读发生跳跃时，再补必要连接词。连接词按实际语义选择，不按词表删除或机械互换；空泛铺垫可删，有功能的逻辑连接保留。真实流程或并列项可以编号，必要顺序保持清楚。
- 方法类内容直接说明判断依据和做法，减少“教你个方法、下面分几步讲”等空泛引导。平等交流不等于虚构经验；假设仍标明为假设，不改成“常见情况”，也不无依据增加“很多人、大家都”等群体判断。
- 专业词只保留本题需要的，按本篇目标受众判断：理解受阻时就近解释；已能理解时不机械补释。避免抽象名词连串、参数堆叠、工整排比和对仗；正文要像聊天，不能像说明书或汇报。

## 直接表达与听懂检查

本节用于所有文案类型的标题、开头、正文、公司段和结尾；从初稿起执行，Humanizer 复审和交付前使用同一标准。已确认分镜只忠实拆分，不借本检查改稿。

### 起稿

先用日常中文说出已知的主体或对象、具体动作或判断。涉及影响时，写清有依据的具体变化，例如哪项费用增加、哪类订单受限、谁提供哪项服务；这些是检查线索，不是每句必须填齐的模板。不要先写一层抽象概括，再让观众自己把它翻译成实际事情。

内部的语义承诺、判断变量、信息关系等用于组织内容，成稿直接讲事实、判断和做法。术语或概括词在本题必要、含义明确且听者能跟上时保留；本节不设抽象词黑名单，也不要求每句重复主语或变成行动指令。

### 一句话直说

每个实质判断先能用一句日常中文直说：对象或场景＋动作或判断。正文以这一句为骨架，其他信息按关系组织；写完整段后，仍能用同一句向受众复述本条核心。

- “绕”的症状：主语出现晚、多层定语或条件套条件、先铺垫后落点。处理：主干前置、条件后置、拆句，不让听者等三个分句才知道在讲谁、做什么。
- “飘”的症状：主语或动作缺失，用“影响、变化、安排、价值、关注”等概括词代替具体事情。处理：用已有事实写清是哪项费用、哪个环节、谁做什么；原文没有的具体内容不补造。
- 一句话塞入多个独立判断时拆句；拆句不切断条件、因果与责任关系。

### 抽象词检查

对经验丰富的行业受众，抽象概括词往往把"谁、做什么、什么结果"遮住了。本节按"一句话直说"的"飘"检查执行，**不设禁用词表，也不设固定兑换表**：凡抽象概括词（逻辑、体系、机制、责任链、权衡、资产、孤例、价值、影响等，**不限于列举的这些**）掩盖了具体主体、动作或事物时，用已有事实写具体；词本身清楚且承载必要判断时可保留。

- 检查问法：这句话换成"谁／什么＋做什么／发生什么"，能不能说清？说不清就是抽象词遮住了事实。
- 改写示范（**只示范改写思路，不是固定兑换句**；按主题和正文灵活组织表达，以说清具体动作或事物为准，不逐词套用）：
  - "这种量级不是孤例" → 可改写为"这类项目这两年不是只签了这一单"
  - "选型逻辑也得跟着变" → 可改写为"选什么房、按什么标准选，都得跟着变"
  - "交付责任链接不接得住后续安装" → 可改写为"后面的运输、安装、配件和技术支持，有没有人从头接住"
  - "都在本地责任链里" → 可改写为"在沙特本地一条线都能跟上"
  - "在两套方案之间来回权衡" → 可改写为"在两个方案之间反复纠结"
- 边界：行业术语（G550、玻璃棉、围护等）是目标受众已知事实，按受众标准保留；不得为改词补造事实或改变因果强度、限定条件。

### 逐句、相邻句检查

- 听者不借助内部分析和资料出处，只看当前句及前文，就能说清正在讲谁或什么、发生了什么或得出了什么判断；不能只知道“有影响、有变化、涉及安排”。用当面向本篇受众解释的语境检查对象、动作和比较时间是否自然明确；日常说法只是辅助判断，不按个人用词偏好否决清楚的表达。
- 指代有明确对象。“这、两件事、同一批货”等找不到唯一所指时，补回必要对象或分别说清；不要把不同范围的事实硬写成同一对象。
- 主体和动作配得上，因果强度与来源一致。谁暂停订舱就写谁；某项条件只影响一个环节时，不写成它决定全部结果。
- 相邻句的转折、因果、条件或补充关系能顺着理解。发生跳跃时补上来源支持的连接信息；已有内容能自然连接时直接往下讲，不插入复述前文的抽象总结。对疑似预告、总结或泛化提醒尝试删除；语义、衔接和必要停顿均不受损且未丢事实时删除。保留过渡句时须指出删除后具体缺失的指代、条件变化、因果或动作关系；“显得完整、语气顺一点、段落需要承接”不能单独作为保留理由。停顿可由断句或标点承担，不靠空话填充。

### 重写与通过

出现上述任一理解缺口，就回到已知事实重写整句，必要时重组相邻句；不能只把原句换成同义词、把逗号改句号或加口头禅。保留有作用的衔接和必要条件，不为短句拆散意思，不为讲得具体补造费用、期限、客户或后果。

先做听懂检查，再按自然语速默读或朗读检查停顿；语法正确、读得顺不等于听得懂。改后复查主体、动作、对象范围、条件和因果强度；两项都通过才交付。仍需观众自行补出关键对象或关系时继续改写；源事实本身缺失则回到事实门，不靠措辞补齐。

### 完整稿的独立审稿与处理记录

完整稿写完后，单独进行一轮审稿；这指独立的检查步骤，不要求另开任务或调用其他代理。通读全文，重点检查段首过渡、段尾总结、公司介绍和结尾：哪句话仍需观众自行翻译成具体事情，哪句话删除后不损失理解，哪个标题承诺尚未得到实际回答。

对发现的每个可疑句，按下表处理；“影响、条件、安排”等词仅是检查线索，不是禁用词，清楚且必要的概括可保留。

| 检查结果 | 处理动作与完成条件 |
| --- | --- |
| 必要信息被概括词遮住，但已有对应事实 | 重写：用已有事实讲清主体、动作、具体变化或条件；事实强度不变，只换同义词不算完成 |
| 只重复前文或预告下文，删除不损失事实、条件和衔接 | 删除：移除后连读相邻句，确认没有遗漏或跳跃 |
| 承担必要事实、限定、解释或衔接，且表达清楚 | 保留：指出保留的信息；过渡句还须通过上面的删除检查 |
| 写具体所需的事实缺失，或正文没有证据回答标题承诺 | 返回事实或可回答门：补资料、移除无关主张，或按证据缩小结论；涉及改变已锁定主题、产品或核心承诺时按上游规则处理，再重新审稿 |

在当前任务临时状态中留下简短处理记录：原句或位置、可观察的问题、所选动作、修改结果（保留时写明必要信息）、相邻句与事实边界复核结果。记录默认不展示、不写入磁盘或确认稿台账；不要求逐句留档、制造问题或改动已经合格的句子。无可疑句时记录本轮检查范围与正文实际回答的核心问题，不以一句“已通过”代替审稿。

区分内容不足和表达抽象：前者返回补证或调整承诺，后者用已知事实重写。保留事实边界时写出已知的具体条件，不用“取决于实际情况”掩盖缺口。不得为补篇幅保留空话，也不得为具体化补造事实。

全部发现项处理完成后，再读修改句及相邻段落，并核对正文是否回答标题。仍有理解障碍、必要证据缺口或未兑现承诺时，不进入交付；后续改动触发复审时，检查最终版本并更新处理记录。若用程序辅助，只能检查记录是否齐全、修改后是否复查；不能以词表命中或记录完整代替语义判断。

## 数字与公司表达

数字只有影响理解、判断或产品区别时才进入口播。可有可无的数量、尺寸、产能、天数不强行补齐；不影响事实含义时可用量级或约数帮助理解，不得因此改变关键新闻数据、技术参数或比较口径。

公司和产品段按 `company-soft-placement.md` 使用明确主体和具体动作，保持直接、有底气。保留有用的衔接，修复主语缺失、逻辑跳跃、概念绕口和突然切广告；不要把每一句切成碎片，也不要为显得口语化添加口头禅。

## 三、反问、设问与概念辨析

- 反问句禁用。“难道……吗”“这不是……吗”“怎么会……呢”改成直接陈述和答案，不用反问催促、教训或逼观众认同。
- 全文设问最多 2 处：开头最多 1 处共鸣或悬念设问，紧接着回答；结尾最多 1 处互动提问。正文中段直接讲事实、条件和动作，少用“怎么判断？答案是……”这类自问自答。问句额度不是必须用满。
- 否定用于说明真实边界，不作为固定的段落起手式。连续采用“否定＋解释”或相同条件句时，检查是否机械重复；需要修复时重组整段，不按指定词组计数或换词规避。真实并列和条件对照需要相同结构时可以保留，条件作用范围及判断强度保持一致。
- 改成句号仍带质问意味的句子也要改。问号计数只做初筛，最后按实际语气判断。

## 四、钩子、正文与新闻

- 外层默认按“钩子 → 正文 → 一个动作”组织，收尾例外按第五节执行；钩子从反常识、利益前置、痛点共鸣、悬念留白、数字冲击、场景代入、冲突对比、提问式中选一种。具体选择见 hook-pattern-library.md，不为套模板补造事实。
- 正文只讲一件事。可用“痛点→方法→结果”、故事线、清单或“结论→例子”；必要条件、比较和原因共同回答一个问题，不拼多个独立知识点。没有结果证据就不写结果承诺。
- 按真实因果、条件、比较、时间或责任关系往下说，衔接按第二节执行；同一意思不在段首段尾反复总结。每段承担一个清楚的信息任务，不要求每段都有独立结论，也不强制补充提醒段。跨段检查是否接续前文所需的解释、事实或做法；只有换词复述同一意思时合并或删除，必要指代和衔接保留。
- 每 5–8 秒安排一个有效信息点或情绪落点，例子尽量一两句话讲完。未有实测语速或录音时，这一项按篇幅门的估算语速作节奏提示，不声称已经按秒验证。节奏用于组织已有信息，不编数字、经历或后果。
- 新闻可以提供背景，也可以承担关键证据；篇幅由本条判断需要决定，不限制为一句。保留必要的发布主体、时间范围、事实和适用条件；不影响判断的细节可移到字幕或资料出处。企业披露保留来源归属，不写成已验证的效果或行业普遍现象。完整出处放稿后。
- 新闻稿正文落点必须是受众的可证判断、边界或动作，新闻事实只作证据；按时间线播报事件、删去新闻叙述后没有留下判断的转播式正文不通过。新闻要素只保留与判断直接相关的部分，其余放资料出处。
- 关键词自然进入正文；不为了埋词重复产品名或扩展话题。

## 五、结尾默认给一个明确动作

正文把答案讲完后，结尾默认给一个与本题相关的明确动作，随内容选择联系、评论、关注、收藏、点赞或已有安排的预告，不默认导向评论区。销售导向可以直接邀请联系东方骆驼；联系话术自然变化，不强制客户先提交一整套资料，不把联系方式前的公司介绍再说一遍。默认不同时索要多个动作。

仅当用户明确要求本条同时兼顾业务转化与互动时，允许一个简短业务对接动作加一个扣题互动问题，先转化、后互动，不叠加点赞、收藏、关注等第三个动作。品牌露出或销售导向本身不触发这一例外；正文介绍公司做什么但未要求观众行动，不计为一个行动引导。互动问题仍按第三节的问句要求执行。

互动围绕本篇已经解释的判断或条件，让目标受众可以直接回答，不预设客户犯错，不用通用的“你们怎么看”。业务对接动作承接前文，并以真实服务为依据；不按是否出现“联系、咨询”等词判定硬广告，也不因改成“把配置发给我们”就自动判定自然。

结尾不再复述整套清单，不另起产品广告。不凭空承诺“我帮你审核”“免费方案”、资料领取或更新日期；采用预告时必须已有对应安排。用户明确要求无 CTA 时，停在最后一个有效事实或判断。

## 六、完整稿验收

1. 脱离标题也能理解对象和场景，开篇引出本题承诺；不检查开头是否出现第二人称。
2. 按理解、朗读、重复表达和语气检查：以平等、直接地说明为主，必要时提醒，修复重复警告、强硬命令、刻意口语词和空泛过渡。不以代词、口语词或指定否定词组的数量判断合格；问句仍按第三节执行，零反问。
